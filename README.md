# to_do_app

אפליקציה לניהול משימות אישיות, נבנתה ב-React כפרויקט סיום קורס.
המשתמשת יכולה להוסיף, לערוך ולמחוק משימות, ולעקוב אחרי ההתקדמות שלהן.

## מה האפליקציה עושה?

- הוספת משימה חדשה עם שם, קטגוריה, תאריך יעד, עדיפות וסטטוס
- עריכת משימה קיימת
- מחיקת משימה (עם חלון אישור לפני המחיקה)
- שינוי סטטוס בלחיצה על תווית הסטטוס: `To Do` ← `In Progress` ← `Completed`
- חיפוש משימה לפי שם
- סינון לפי קטגוריה, עדיפות וסטטוס
- מיון לפי תאריך יעד, עדיפות או קטגוריה
- כרטיסי סיכום: סך הכל משימות, כמה לביצוע, כמה בתהליך וכמה הושלמו
- משימה שתאריך היעד שלה עבר ולא הושלמה מסומנת באדום (Overdue)

## איפה נשמרים הנתונים?

המשימות נשמרות ב-`localStorage` של הדפדפן.
כלומר, המשימות נשארות גם אחרי רענון הדף, אבל הן שמורות רק בדפדפן ובמחשב שבהם עובדים.
